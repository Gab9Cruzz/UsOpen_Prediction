Sobre el proyecto

Qué construí y qué logré

Un sistema de punta a punta que predijo el US Open 2026 en vivo: desde la descarga de datos y el modelo estadístico hasta un dashboard público que se actualizó solo durante todo el torneo, sin servidor y sin intervención manual.

Lo construido

  • Modelo de saque/resto: probabilidad punto a punto (Barnett-Clarke) con métricas de pista dura ajustadas por la fuerza de los rivales y decaimiento temporal.
  • Simulación Monte Carlo: juego → set → partido → cuadro de 128, con las reglas reales del US Open, 10.000 veces por actualización.
  • Datos en vivo: el sorteo oficial y los resultados reales se ingieren automáticamente; cada partido jugado se fija como hecho y solo se simula lo que falta.
  • Automatización: GitHub Actions regeneró la predicción durante el torneo y la publicó en GitHub Pages como JSON estático.

Rigor y resultados

  • Validado antes de usarlo: backtest con 2.032 partidos reales del US Open 2010-2025, con corte temporal estricto (sin data leakage), contra ranking ATP, Elo de superficie y moneda al aire.
  • Brier 0.193 en el backtest, a la par de un Elo de superficie puro pero conservando la estructura de juegos y sets.
  • 139+ tests automatizados (pytest): reconstrucción del cuadro, no-leakage, motor de simulación, ingesta en vivo y exportadores.
